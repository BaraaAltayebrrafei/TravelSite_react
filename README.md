# Travel Site (React)

A responsive multi-page travel website built with React and React Router.

## Features
- Multi-page navigation with React Router (Home, Services, Products, Sign Up)
- Responsive navbar
- Full-screen hero section
- Destination cards built from reusable `Cards` / `CardItem` components
- Reusable `Button` component and footer

## Tech
React · React Router · JavaScript · CSS

## Project structure
src/
├── App.js              # Routes
└── Components/
    ├── Navbar, HeroSection, Cards, CardItem, Button, Footer
    └── pages/          # Home, Services, Products, SignUp

## Run locally
git clone https://github.com/BaraaAltayebrrafei/TravelSite_react.git
cd TravelSite_react
npm install
npm start

Then open http://localhost:3000
